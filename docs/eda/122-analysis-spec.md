- **Spec/version and owning issue:** `122-established-class-anomaly/v1`, [ML #122](https://github.com/Caraway-Labs/one-health-lyme-gap-atlas-machine-learning/issues/122), parent [ML #22](https://github.com/Caraway-Labs/one-health-lyme-gap-atlas-machine-learning/issues/22). - **Question / decision / allowed interpretation:** Inside the established-tick class, which counties are unusual on size, social vulnerability, uninsured percentile, or rural-urban code, and does an isolation forest flag a different set than a robust z-score and a robust-covariance distance? The decision is keep, revise, stop, or follow-up for a data-quality review list. An anomaly score is a review flag. It is not incidence, risk, causation, a hot spot, or a training label. `No records` and `Unknown` are not negatives. A missing human floor is not zero. Do not train on the Tier 1 score or on latent-class membership.
- **Estimand:** For the predeclared class, the within-class flag rate of each frozen rule, the agreement of those flags, the share of each flag set whose largest robust z-score is a named feature, and the overlap of the primary flag set with the 228-county double gap when that gap is reproduced from published columns. Uncertainty for the primary flag rate and for the double-gap overlap share is a state-cluster bootstrap percentile interval. County names and county-level numbers are confined to the lab score table, the results write-up, the pull-request body, and the issue comment, as amended below. Charts and other Drive files stay aggregate.

- **Missingness rule:** Do not impute. Do not replace a gap with zero, Established, or Present. A class row is excluded from the fit when population is null or not positive, when either percentile or the rural-urban code is null, or when the rural-urban code is not an integer from 1 through 9. The exclusion count is a data-quality result, separate from the anomaly flag. A duplicate `FIPS`, a `FIPS` that is not five digits, a row whose tick status is not Established, or a state missing from the #109 Census map stops the fit. The 228-county predicate, evaluated inside the class, is `HUMAN_STATUS = 'no_county_linked_record'` and `BURGDORFERI_STATUS = 'Present'`. The 810-county predicate is `HUMAN_STATUS = 'no_county_linked_record'` inside the same class. If the 228 predicate does not equal 228, say that the published columns did not reproduce it, and report overlap with the 810 predicate.
- **Exploratory or confirmatory:** Confirmatory for the class size 1,404, the release pin, and the 228 predicate count. The flag rates, agreement, driver shares, and bootstrap intervals are the prespecified descriptive results of the rules below. Epic #22 section 4.1 did not record an isolation-forest flag count. Nothing in that section is used to change a threshold, a seed, or a contamination setting after the fit.
- **Method / assumption rationale:** Baselines first, then the forest. A robust z-score answers whether one feature is far from the class median in median-absolute-deviation units, which is the direct reading of size, vulnerability, insurance, or rurality. A robust-covariance distance answers whether the county is far in the joint shape of those features, including correlation. The forest is a second screen. It adds a review set only when its flags stay stable across seeds and do not match either baseline at the same flag count.

  Frozen settings:

  | Rule | Setting |
  | --- | --- |
  | Robust z | Median and MAD. Scale is `1.482602218505602 * MAD`. Flag when the largest absolute z exceeds 3.5. |
  | Robust distance | `sklearn.covariance.MinCovDet`, `support_fraction=0.8`, `random_state=1222026`, on the transformed features. Flag when squared Mahalanobis distance exceeds the chi-square 0.975 quantile with degrees of freedom equal to the number of features kept (df 1–4 quantiles 5.023886187314888, 7.377758908227871, 9.348403604496148, 11.143286781877796). On failure, record the failure. Do not substitute the classical covariance. |
  | Isolation forest | `sklearn.ensemble.IsolationForest`, 200 trees, `max_samples='auto'`, `bootstrap=False`, `n_jobs=1`, fit on the same transformed features. The log is the population scaling. Do not z-score before the forest. Primary contamination 0.05. Sensitivity 0.02, 0.05, and 0.10. Seeds 1222026 and 1222027. The stored score is the negation of `decision_function`, so a larger score is more unusual. The flag is `predict == -1`. |
  | Agreement | Jaccard on the flag sets. Matched-count Jaccard takes the same number of highest primary-forest scores as the baseline flagged, breaking ties by `FIPS`. The forest adds a distinct set only when the seed-to-seed Jaccard at contamination 0.05 is at least 0.90 and both matched-count Jaccards are below 0.80. |
  | Dominant feature | The feature with the largest absolute robust z. `tie` when the top two are within 1e-12. `joint` when the largest absolute robust z is below 2.5. Shares use the primary forest flags. The same shares are stored for the two baselines. |
  | Uncertainty | 400 state-cluster bootstrap draws, seed 1222026, percentile 2.5 and 97.5, for the primary flag rate and for the share of primary flags inside the 228 predicate. A draw with no primary flags is skipped. If fewer than 100 draws remain, the interval is not estimable. The interval describes resampling of states. It is not a causal interval. |
  | Small cells | A count from 1 to 10 is not published. A composition whose omitted remainder is 1 to 10 is not published at all. A zero on a denominator of at least 11 is kept. |

- **Spatial / temporal dependence:** Counties in one state share reporting rules. The bootstrap resamples states. Region tables are the score display. No p-value is reported. Population is the 2022 county layer, SVI is 2022, the rural-urban code is 2023, and tick status is cumulative through 2025. They are not one time base.
- **Effect-size / uncertainty output:** Flag counts and rates, Jaccard values, driver shares, region score percentiles (0.25, 0.50, 0.75), and the two bootstrap intervals. Histogram bins are prespecified: population edges 0, 10000, 25000, 50000, 100000, 250000, 500000, 1000000, 20000000; log-population edges are the natural logs of 1000, 10000, 25000, 50000, 100000, 250000, 500000, 1000000, 20000000; percentile edges are tenths from 0 to 1 on the modeled scale; rural-urban bins are the integers 1 through 9. Values outside an edge list form one underflow bin and one overflow bin.
- **Key caveat / stop conditions:** Stop if the context check is not `prod_select` pass, `scratch_write` pass, and `prod_write_denied` pass. Stop if the live release id or bundle SHA differs from the #109 pin. Stop if the Established count is not 1,404, if `FIPS` are not unique five-digit ids, or if any class state is outside the Census map. Stop if fewer than two features remain. Do not read `RESTRICTED_CDC_*`, `RAW`, `GOVERNANCE`, `KNOWLEDGE_GRAPH`, historical CDC snapshots, or any column other than the list above. Do not select payload, part text, limitation text, or geometry. A query still running at 10 minutes is cancelled. County feature rows may stay in memory for the fit. They are not written to a data extract, a chart, or Drive. County scores, including the county name, are inserted only into `ONE_HEALTH_LYME_GAP_ATLAS_ML_LAB.EDA.COUNTY_ANOMALY_SCORES_122`. The results write-up, pull-request body, and issue comment may name counties, as amended below.
- **Result disposition:** **PLANNED.** After the fit, apply this rule without changing it. **stop** when a gate above fails. **revise** when any fit row is excluded for data quality, the 228 predicate is not 228, MinCovDet fails, or the seed-to-seed Jaccard at contamination 0.05 is below 0.90. **follow-up** when the run is otherwise valid and either the forest adds a distinct set or one feature, tie, or joint label accounts for at least 0.60 of the primary flags. **keep** when the run is valid, the forest does not add a distinct set, and no driver share reaches 0.60. keep and follow-up both mean the score can be reviewed as a data-quality flag. Neither authorizes a production model, a visit ranking, or a public map.
