# ML scientific review

Use when independent review is requested. Read repository `AGENTS.md`,
approved methodology, and available experiment/evaluation evidence. Examine
leakage, holdout integrity, baselines, uncertainty, reproducibility, and claim
limits; distinguish evidence from assumptions. Record findings without treating
review as approval. Stop on missing evidence or unapproved public-health
meaning. Story #45 owns the full review workflow and gate.
